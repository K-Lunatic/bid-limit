# 분실물 극장 미술 교체 — 2026-11-04

캐릭터·홀·수선 장갑·행동표 그림·가구는 Codex 내장 imagegen으로 생성/편집했다. `*-prompt.txt`에 입력문을 보존한다. 가구 프롬프트만 당시 저장 오류로 원문이 없으며 해당 파일은 명시한 재구성문이다. 생성물은 픽셀풍 원본이므로 게임용 인형은 별도 정규화한다.

현재 몸통은 `puppet-bald-master.png`, 머리는 `hair-parts-master.png`가 원본이다. `tools/import_cozy_puppet.py`를 Pillow가 설치된 Python에서 실행하면 `cozy_v3/frames/00..07.png`와 `hair/0..2.png`를 재생성한다. 96×128 몸통, 하단 기준 113, 최대 폭 72, 64색 공유 팔레트, 이진 알파, 최근접 샘플링을 사용한다. `registration-v3.json`과 `art_layout.gd`에 각 동작의 실제 단추 중심을 기록한다. 머리 파츠는 64×48, 밑동 (32,46), 가까운 단추 중심에서 (-15,+2)에 고정한다. 머리는 몸통 뒤, 모자 뒷면은 머리 앞, 모자 앞면과 안경은 얼굴 앞이다.

`cozy_v2/frames`는 첫 합성 인형 원본/타이틀 포스터용 보관본이다. 실행 중 인형은 머리 없는 v3 몸통과 별도 머리 파츠를 조합한다. 머리 모양 0/1/2는 쓸어 넘김/짧은 곱슬/높은 묶음이다. 머리색은 파츠 재질에서만 바꾼다.

배경은 `auction-hall-cozy-v2.png`, 진행자는 `mending-glove-v2.png`, 가구는 `hall-props-cozy-v2.png`, 카드 그림은 `auction-card-art-cozy-v3.png`다. 기존 파일은 되돌릴 수 있게 보존했다. 렌더링 시 인형과 배경에 공통 실내 색감을 적용한다. 배경의 반복 패널 연결과 작은 화면의 카메라 배율은 후속 미술 개선 지점이다.

세계관과 현재 규칙은 `WORLD.md`, `GAME_SETTINGS.md`가 기준이다. 본 변경에서 웹 내보내기는 하지 않았다.
