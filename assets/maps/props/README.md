# Hall prop kit v1

Art source: host_image (built-in image_gen), generated 2026-11-03. Reference: auction-hall-background-v1.png, palette/material only. Original retained as hall-props-master-v1.png; runtime hall-props-v1.png has four 96×96 cells, nearest-neighbor, native alpha. No alpha keying or painted background.

Prompt: Create one game-ready environment prop sprite sheet for BID! sock-puppet auction hall, using the attached room image ONLY as palette/material/style reference, not as the output composition. Transparent RGBA background. Exactly four separate sprites in equal 2x2 grid cells with generous transparent gutters, no labels or text, no floor/background. Upper left: one gilded oval portrait of a pompous sock puppet, face with button eyes. Upper right: one antique brass wall sconce with three tiny warm amber candles. Lower left: one closed stack of two old leather auction trunks with brass clasps. Lower right: one tall leafy plant in ornate bronze pot. Strict front side-on 2D view, crisp authentic low-resolution pixel art, coherent dark walnut/burgundy/muted teal/antique gold palette, warm light from upper left. Large intentional pixel clusters, no smooth gradients, no antialiasing, no cast floor shadows, no baked checkerboard. Each object fully contained in its own cell, no overlap. Props must suit the same scale as a sock puppet character of 96x128 logical source pixels; final each cell will be reduced to 96x96 nearest-neighbor, so silhouettes and detail must survive that reduction. Output square sheet.

Layout: layout-v1.json. Perlin chooses variants and bounded horizontal offsets; all props render behind the walk lane. The auction stage, appraisal area and shop are excluded. This kit does not replace the baked architectural background; background joins still need visual work. Runtime uses the existing host-fixed map seed; room-specific seed synchronization is not implemented.
