# 현재 카드 그림과 틀

그림은 `auction-card-art-cozy-v3.png`를 사용한다. Codex 내장 이미지 생성으로 새 인형·분실물 극장에 맞춰 편집한 4×3 원본이며, 프롬프트와 원본은 `assets/art-direction/cozy-v2/`에 보존했다.

틀은 `scripts/card_face_ui.gd`의 공통 픽셀 UI다. 크림색 천 바탕, 박음질, 상단 행동명, 오른쪽 위 실밥 코스트, 가운데 그림, 하단 종류와 한 줄 효과를 고정한다. 색상 외에도 종류를 글자로 표시한다. 뒷면은 청록 천과 네 구멍 단추 문장이다.

손패·드래그·덱 편성·상점·공개 제출·머리 위 카드에 같은 틀을 사용한다. 그림이 있는 면은 코스트 0도 숫자로 표시한다. `auction_game.gd`의 카드 정의에 실제 이름·짧은 이름·종류·효과·농담을 따로 둔다. 농담은 드래그 상세 보기에서 읽는다.

`weapon-card-art-v1.png`와 `auction-card-art-v1.png`는 이전 원본 보관용이다. 현재 무기별 공격 그림은 사용하지 않는다.
